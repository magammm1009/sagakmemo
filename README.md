# 사각메모

윈도우 메모장만큼 가벼운 윈도우·맥 메모장입니다. 사각 시리즈([사각책상](https://github.com/magammm1009/sagakstory))의 한 가족입니다.

- 왼쪽 바인더 목록에서 메모를 고르고, 메모는 내가 고른 폴더에 txt 파일 하나씩 저장됩니다.
- 그 폴더를 Dropbox·iCloud Drive·OneDrive 안에 두면 여러 기기에서 같은 메모를 씁니다. 프로그램이 직접 글을 인터넷으로 보내지 않습니다.
- 입력이 멈추고 1초 뒤 저절로 저장, Ctrl+S(⌘S)로 바로 저장. 기기 안에 이전 판(복구 사본)을 남깁니다.
- 서식 셋: 취소선·굵게·형광펜(네 가지 색). 파일에는 `~~` `**` `==` 기호로 남고, 화면에서는 기호가 보이지 않습니다. 복사하면 글자만 나갑니다.
- 돋보기(Ctrl+P / ⌘P)로 제목과 본문을 함께 찾습니다.
- 작성 시점 확인: 저장할 때마다 국제 시점 확인 기관(DigiCert·Sectigo)의 서명으로 작성 시각을 남깁니다. 글은 보내지 않고 지문(SHA-256)만 보냅니다. [파일 → 작성 증명 내보내기]로 원고·확인서·검증 방법을 한 폴더로 꺼낼 수 있습니다(표절 시비에 대비한 보조 증거).
- 무료, 자동 업데이트.

## 내려받기

[Releases](https://github.com/magammm1009/sagakmemo/releases/latest) 에서 내려받습니다.

| 운영체제 | 파일 |
|---|---|
| macOS 12 이상 (Apple 실리콘·인텔 모두) | `SagakMemo_<판>_universal.dmg` |
| Windows 10·11 (64비트) | `SagakMemo_<판>_x64-setup.exe` |

`.app.tar.gz` 와 `latest.json` 은 프로그램 안 자동 업데이트용이라 내려받지 않아도 됩니다.

## 설치와 첫 실행

### 맥

1. `SagakMemo_<판>_universal.dmg` 를 열고 '사각메모'를 '응용 프로그램(Applications)' 폴더로 끌어다 놓습니다.
2. 처음 켜면 "Apple은 '사각메모'에 악성 코드가 없음을 확인할 수 없습니다" 같은 창이 뜹니다. **[완료]** 를 누르세요(휴지통으로 옮기지 마세요).
3. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래쪽 '보안'의 "'사각메모'이(가) 차단되었습니다" 옆 **[그래도 열기]** → 암호 입력 → 다시 뜨는 창에서 **[그래도 열기]**.
4. 이 과정은 처음 한 번뿐입니다. 이후 새 판은 프로그램 안에서 '지금 업데이트'로 받습니다.

애플 개발자 서명이 없는 개인 제작 프로그램이라 나오는 절차입니다.

### 윈도우

1. `SagakMemo_<판>_x64-setup.exe` 를 실행합니다.
2. 파란 창 "Windows의 PC 보호"가 뜨면 **[추가 정보]** → **[실행]**.
3. 관리자 권한 없이 내 사용자 계정에 설치됩니다. 이후 새 판은 프로그램 안에서 '지금 업데이트'로 받습니다.

### 처음 켤 때

메모를 둘 폴더를 고르는 화면이 뜹니다. 고른 곳 안에 '사각메모' 폴더를 만들고 메모를 txt 로 저장합니다. Dropbox·iCloud Drive·OneDrive 를 고르면 다른 기기에서도 같은 메모가 보입니다. 나중에 [환경 설정]에서 바꿀 수 있습니다.

## 알려진 제약

- 코드 서명이 없어 처음 한 번 위의 첫 실행 절차가 필요합니다.
- 맥에서는 업데이트 뒤 문서·Dropbox·iCloud 폴더 접근 허용을 다시 물을 수 있습니다.
- 이 저장소에는 설치 파일만 올립니다. 소스 코드는 공개하지 않습니다.
