# 사각메모

윈도우 메모장만큼 가벼운 윈도우·맥 메모장입니다. 사각 시리즈([사각책상](https://github.com/magammm1009/sagakstory))의 한 가족입니다.

- 왼쪽 바인더 목록에서 메모를 고르고, 메모는 내가 고른 폴더에 txt 파일 하나씩 저장됩니다.
- 그 폴더를 Dropbox·iCloud Drive·OneDrive 안에 두면 여러 기기에서 같은 메모를 씁니다. 프로그램이 직접 글을 인터넷으로 보내지 않습니다.
- 입력이 멈추고 1초 뒤 저절로 저장, Ctrl+S(⌘S)로 바로 저장. 기기 안에 이전 판(복구 사본)을 남깁니다.
- 복사·붙여넣기는 글자만 오갑니다. 취소선(`~~글~~`)으로 할 일 목록을 지울 수 있습니다.
- 무료, 자동 업데이트.

## 내려받기

**아직 첫 판을 준비하고 있습니다.** 나오면 [Releases](https://github.com/magammm1009/sagakmemo/releases/latest) 에 올립니다.

| 운영체제 | 파일 |
|---|---|
| macOS 12 이상 (Apple 실리콘·인텔 모두) | `SagakMemo_<판>_universal.dmg` |
| Windows 10·11 (64비트) | `SagakMemo_<판>_x64-setup.exe` |

`.app.tar.gz` 와 `latest.json` 은 프로그램 안 자동 업데이트용이라 내려받지 않아도 됩니다.
